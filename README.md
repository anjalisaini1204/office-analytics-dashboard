# office-analytics-dashboard# Workforce Analytics Dashboard | Power BI

## 📊 Project Overview

The **Workforce Analytics Dashboard** is a data analysis and visualization project developed using Microsoft Power BI. It focuses on exploring workforce-related data and presenting meaningful insights through interactive dashboards and visual reports.

The project helps understand employee demographics, job roles, educational qualifications, payment patterns, and hiring trends. It transforms raw workforce data into visual information that can support better understanding and data-driven decision-making.

## 🎯 Project Objectives

- Analyze employee demographics and workforce distribution.
- Understand employee distribution across different job titles.
- Explore workforce composition by gender and age groups.
- Examine employee education and qualification patterns.
- Analyze payment-related information.
- Identify hiring and workforce trends through visualizations.
- Present key information in an interactive and easy-to-understand dashboard.

## 📈 Dashboard Analysis

The dashboard explores different aspects of workforce data, including:

### 2. Job Role Analysis
- Employee distribution across job titles.
- Comparison of workforce categories.

### 3. Education Analysis
- Employee qualifications and education levels.

### 4. Payment Analysis

### 5. Hiring Trends

## 🚀 How to Use This Project

Follow these steps to explore the dashboard:

1. Clone this repository:

   ```bash
   git clone https://github.com/anjalisaini1204/office-analytics-dashboard.git
   ```

2. Navigate to the project folder:

   ```bash
   cd office-analytics-dashboard
   ```

3. Open the `analysis` folder.

4. Download and open `OFFICEANALYSIS.pbix` using **Microsoft Power BI Desktop**.

5. Interact with the dashboard to explore workforce data and visualizations.

6. Refer to the `raw_data` folder to access the source Excel dataset.

7. Open the presentation in the `result` folder for a summary of the project.
